# A 股午评操作计划

## 目标

输出一份能直接用于午后决策的观察计划：今天是否值得参与、优先看什么板块和个股、什么信号出现才参与、什么情况立即放弃、最大风险暴露是多少。所有动作都是条件计划，不预测下午必涨必跌，不触发下单。

数据工具与口径见 `references/data_sources.md`，成稿结构见 `references/report_template.md`。

## 数据与时间边界

- 以目标交易日 Asia/Shanghai 11:30 为行情截面，注明行情截止和生成时间。11:30 前只能输出盘中观察；非交易日说明休市。
- 午后补跑仅使用可还原的上午数据。11:30 后消息单列为午间变量，不能倒推上午行情原因。
- 所有指数、市场宽度、涨跌停、炸板率、连板、板块、个股、均线和价位必须来自本次实际数据。无法取得就删除相应结论，不估算、不用模板占位。
- 半日量能只与上一交易日同期比较。市场范围、时点或单位不一致时只报绝对值，不判断放缩量。
- 热度不等于强度，板块上涨不等于资金净流入，当前封板不等于收盘晋级，消息相关不等于价格因果。

## 决策顺序

### 1. 判断环境

综合指数、宽度、量能、涨跌停、高位反馈与主线扩散，将环境归为一种：

- **强势共振**：指数、宽度、主线与高位反馈多数同向改善。
- **结构性行情**：指数或宽度一般，但存在有扩散、有核心、有持续性的明确主线。
- **震荡分化**：信号互相抵消，轮动快，缺少压倒性主线。
- **高位分歧**：主线仍在，但核心或高位股承接恶化，板块内部明显分化。
- **情绪退潮**：宽度、高位反馈与主线强度共同恶化，亏钱效应扩散。

不要用单一指标定级。关键数据缺失时降低置信度，并把操作倾向收缩一档。

### 2. 给出市场暴露上限

输出的是基于市场环境的计划仓位上限，不是用户的个性化仓位指令：

| 环境 | 默认操作倾向 | 计划总仓上限 |
| --- | --- | --- |
| 强势共振 | 积极但等确认 | 50%–70% |
| 结构性行情 | 聚焦主线、分批确认 | 30%–50% |
| 震荡分化 | 小仓试错或持仓观察 | 10%–30% |
| 高位分歧 | 降低仓位、只做强确认 | 0%–20% |
| 情绪退潮 | 防守或暂停新开仓 | 0%–10% |

缺少账户规模、已有持仓和单笔风险预算时，不给单只个股精确仓位或账户最大亏损金额。若用户提供这些参数，再按“单笔风险金额 ÷ 入场与失效位价差”计算数量，不能拍脑袋给比例。

### 3. 排板块优先级

最多给一个 S 级、一个 A 级和一个 B 级方向：

- **S 级主攻**：至少具备核心股强度、板块扩散、持续性、成交确认中的三项；写清当前阶段、参与方式和放弃条件。
- **A 级观察**：有逻辑或局部强度，但缺少一项关键确认；写清升级为 S 级需要看到什么。
- **B 级回避**：核心负反馈、后排收缩、事件风险或趋势破坏明确；写清回避原因。

没有满足标准的 S 级方向时明确写“无 S 级主攻”，最终动作只能是观察、持仓管理或等待，不能为了模板完整强行选板块。

### 4. 建候选池

候选不超过三只，优先覆盖不同角色：核心龙头、趋势中军、低位补涨。每只必须包含：代码与名称、板块角色、午盘状态、参与触发、放弃条件。只有同时满足以下要求才能入选：

- 已核验午盘实时行情、成交和上午高低点；涉及 5/10 日线或平台突破时，已取得相应日线数据。
- 已核验所属板块和代表性，不把随机涨幅靠前个股称为核心。
- 已检查当日公告或重要消息；无法完成公告与流动性核验时标为“仅观察”，不给参与触发。
- 触发条件包含个股自身确认和板块同步确认；单只个股异动不能独立触发。
- 放弃条件与参与逻辑一一对应。不得使用没有来源的“分时均线”、支撑位、百分比阈值或止损价。

没有合格候选时可以输出空候选池。不得无条件使用“买入、卖出、加仓”等命令，统一使用“允许纳入计划、保持观察、放弃该计划”。

### 5. 安排午后执行

时间计划服务于确认，不是三个时段都必须交易：

- **13:00–13:20**：只验证上午主线是否回流、核心是否承接，不追开盘瞬时拉升。
- **13:20–14:00**：验证板块扩散和成交确认；只有环境、板块、个股三层同向，候选才从观察升级。
- **14:00–收盘**：评估持续性和隔日风险；主线转弱时取消计划，不因已有观点强行参与。

最终只给一个“今天只做什么”和一个“如果确认不出现怎么办”。避免把所有情景列完后让读者自行选择。

## 输出要求

- 使用 `references/report_template.md`，正文约 700–1100 字；数据不足时主动缩短。
- 第一屏直接给市场状态、操作倾向、计划仓位上限、核心策略和一句话结论。
- 环境表只保留本次拿到且能影响判断的数据；缺失项不占行。
- 数据只出现一次，后文解释含义，不重复报数。
- 每个板块与个股计划均写参与条件和放弃条件；未达到条件时结论就是不参与。
- 报告中明确区分事实、判断和待验证条件，但不机械给每句话贴标签。

## 发布前自检

- 市场环境是否由至少两类独立证据支持？仓位是否与环境等级一致？
- S/A/B 是否真正有差异？没有 S 级时是否停止生成参与型个股计划？
- 每只候选是否核验了代码、板块、行情、成交和消息？触发与放弃是否能在午后实时判断？
- 是否出现无来源的均线、关键价、炸板率、连板高度、精确仓位或止损？有则删除或补数据。
- 午后时间表是否只在信号确认后允许升级，而不是固定时点买入？
- 最终清单能否回答：做不做、做什么、等什么、何时放弃、风险上限？
