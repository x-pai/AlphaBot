# A 股午盘快报

## 目标

将复杂盘口压缩为“结论 → 结构 → 午后关键变量”。午评的价值不是复述行情，而是说明上午最有交易含义的变化、市场正在奖励或惩罚什么，以及下午哪一个变化最可能改变判断。

这是独立的午评任务。盘后 Skill 仅作为数据工具调用参考，不继承其九段式、次日计划或交易打法。

## 数据与时间边界

- 使用本次实际开放的数据工具，调用参数与字段检查见 `references/data_sources.md`。工具不可用时允许降级，不凭文档宣称已连接。
- 行情以目标交易日 Asia/Shanghai 11:30 为截面。报告注明行情截止时刻和生成时间；实际数据早于 11:30 时标明延迟。11:30 前执行只能称盘中快照，非交易日说明休市。
- 午后补跑只用目标日上午可追溯的快照或分时序列，不拿下午最新值或全天日 K 回填。新闻核对发布日期及时间：上午消息可用于解释上午；11:30 后、生成前且不晚于 13:00 的消息单列“午间变量”，不能倒推上午原因。
- 数字必须可追溯至实际返回或已阅读的来源正文。成交额统一市场范围、币种和单位；比较基准只能是上一交易日同一时点，不能拿昨日全天或多日均值充当同期。
- 缺失数据不补造。没有可靠同期量能就不判放缩量；没有资金流证据只能推断市场风格，不能声称资金实际净流入或席位身份。核心行情与广度均无法核验时，输出数据不足说明，不强行定调。

## 分析顺序

1. **判断市场状态。** 同时看指数、广度、量能和赚钱效应，先判断风险偏好是扩张、收缩还是结构性分化。不要用“上涨/下跌”代替状态判断。
2. **识别交易结构。** 回答资金上午主要在做什么：主线加强、主线分歧、高低切、防御承接、权重维稳或无序轮动。必须给出能区分这些状态的证据；没有资金流数据时写“盘面呈现”，不写“资金流入”。
3. **评估主线质量。** 最多写一个主导方向和一个对照方向。至少从扩散度、核心股表现、持续性、消息验证四项中取两项；只知道板块涨跌时，不把它升级为主线。
4. **找出关键反证。** 选择一项最可能推翻当前判断的上午事实或缺口。反证不能只是“仍需观察”，要说明它削弱了哪一层结论。
5. **压缩午后变量。** 只保留 1 个主验证变量和最多 1 个辅助变量。它们必须来自上午数据，且能改变结论；多个高度相关的指数和涨跌家数不能拆成三条重复条件。

事实与解释在句子层面区分。紧凑数据表标“事实”，观点段标“判断”，观察表标“待验证”，避免每句话机械重复标签。

## 报告组织

使用 `references/report_template.md` 的骨架，默认正文约 350–550 字，最多 700 字。最终只交付 Markdown 正文，由自动化负责发布与通知。

### 第一屏：30 秒结论

- 标题应概括当日矛盾，不用“机会来了”等口号，不固定写成放量上涨。
- 开头 50–80 字包含：市场状态、交易结构、下午唯一的核心观察。第一句必须带观点，不能只是“三大指数下跌、个股跌多涨少”。
- 接一行紧凑数据带，放三大指数、半日成交和市场广度；不默认使用表格，不在正文再次逐项复述相同数字。

### 正文：3 分钟理解

- 用两个短段解释“为什么这么看”：第一段讲市场状态，第二段讲交易结构和主线质量。每段必须增加新信息，不能换一种说法重复快照。
- 主线与情绪融入证据链，不另写板块清单或整套情绪仪表盘。若拿不到核心股与扩散证据，明确称“相对抗跌方向”或“局部活跃”，不要称主线。
- 没有分时证据不写“冲高回落”“承接增强”等路径判断；没有资金数据不把板块涨跌写成确定的资金迁徙。
- “分时均价”“关键价位”“持续 N 分钟”等精确条件，必须来自工具直接字段或说明计算方法。不得为了显得专业而临时计算、猜测或任意设定。

### 结尾：下午验证卡

不用四列表格。写一个“主验证”和可选的“辅助观察”，每项 1–2 句：午盘基准 → 下午看什么 → 出现后如何调整判断。

- 对象必须具体，例如已取到数据的指数、主线核心股或同口径上涨家数，不能只写“关注量能与情绪”。优先选择能够代表核心矛盾的对象，不机械凑齐指数、主线、广度三项。
- 条件必须可观测：引用真实上午高低点、明确时间窗口内能否站稳、广度是否持续扩散等。数值基准来自数据；观察窗口属于分析设定，不能冒充历史事实。
- 不把一个瞬时跳动当作确认，不随意造出百分比、价位或精确触发线。
- 三种涨跌情景全部罗列不能替代核心判断。只写与本文判断有关的确认和反证，不追求覆盖所有可能性。
- 结束用一句话写明“出现什么，当前判断需要撤回或降级”。该句不能把前面所有条件再重复一遍。不固定附加低吸、追涨、控仓或仓位比例。

## 发布前自检

- 首屏能否独立说明当前判断与核心矛盾？删掉行情数字后，是否仍是能套用任意一天的空话？若是，重写。
- 每个判断能否指回事实？下午观察条件能否确认或推翻同一个判断？不能相互脱节。
- 同一数据是否出现超过两次？若快照已经给出指数和广度，正文只解释含义，不再逐项报数。
- 验证项是否彼此独立？若三个条件都只是在描述市场反弹，合并成一个主验证变量。
- 日期、时点和市场范围一致；无下午数据、最终晋级率或当日盘后龙虎榜混入。
- 每个具体数值和个股都来自本次证据；分页不完整时不概括全市场梯队。
- 没有真实数据时明确收缩结论，不为了模板完整而凑内容。
- 报告模板中的方括号是写作提示，交付前全部填入或删去。执行 Prompt 仅使用系统支持的日期变量，见根目录 `prompt.md`，不要把报告骨架直接当执行 Prompt。
