# 午评数据调用参考

仅沿用现有盘后 Skill 的数据调用经验，不继承其分析逻辑。先检查本次开放的工具及参数 schema；以下参数是调用线索，连接状态、字段、日期与单位均以实际返回为准。

## 最小取数集

| 需求 | 优先工具 / 参数线索 | 核验事项 |
| --- | --- | --- |
| 三大指数 | data_quote，codes=sh000001,sz399001,sz399006 | 核验实际 price、prev_close、change_percent 等字段；日期和时刻须对应目标日上午 |
| 市场广度与累计成交 | data_changedist，type=0 | 检查涨跌平、涨跌停、totalAmount 等实际字段的单位、时点及覆盖范围；amountChange 不自动视为昨日同期 |
| 市场背景或风格 | data_market_overview，按需选 updown / rotation / summary | 各子组可能更新不同步或仍为前日数据；多日均值与日线技术指标不替代午盘同比较基准。不默认拉 all |
| 重点方向 | data_hot，kind=board；data_sector，mode=list、scope=sw1 | 热度不等于涨幅；行业清单可能不含行情，必要时查询板块或成分的实际报价 |
| 代表股消息 | data_news，symbol=实际代表股、type=3；data_notice | 核对正文、发布时间和证券身份；只取与核心判断相关的消息 |
| 上午走势（确有需要时） | data_minute / data_kline | 按实际 schema 取分时并截取目标日上午；累计成交量与单根量不能直接混加 |
| 候选股日线 | data_kline，使用实际股票代码与日线周期 | 只有取得完整日线后才能引用 5/10 日线、平台和趋势；复权口径保持一致 |
| 候选股行情与流动性 | data_quote / data_fund_flow | 核验现价、上午高低点、成交额和相对板块表现；资金流字段注明供应商口径 |

## 通达信替代路径

- 指数：tdx_quotes，上证 code=000001 / setcode=1，深成指 399001 / 0，创业板 399006 / 0；参数类型按实际 schema。其他证券先查 tdx_lookup_stock，不能猜市场代码。
- 重点题材、涨跌停及连板：tdx_screener，message 使用明确查询条件。pageSize=20 只是单页大小，需核验总数与分页；不能因单页数量少就判梯队断层或晋级失败。
- 分时：tdx_kline，仅采用工具支持的分钟周期，核对时间戳。午后补跑必须有历史午盘快照或可还原的上午序列。
- 消息：wenda_news_query / wenda_notice_query，按工具 schema 查询重点方向或实际代表股。
- 候选股：tdx_quotes 核验午盘行情与成交；tdx_kline 核验日线和分钟走势；tdx_security_deep_info 或公告查询补充基本风险。没有对应数据时不得生成均线、平台或精确触发位。
- 未知或未返回的字段不做推定，指数附带广度数据须核验市场覆盖，不能把多个重叠成分统计直接相加。

## 同期量能与媒体补充

工具没有上一交易日同期数据时，可用本次实际可用的联网检索搜索“A股午评 财联社 + 目标日期”“A股 半日成交 + 目标日期”。读取正文核对日期、发布时间、沪深/含北交所口径以及增减单位，不能直接引用搜索摘要，也不能保证午报包含炸板率或连板数。

较上一交易日同期变化不称“同比”；金额增减与百分比不能混用。若来源仅给金额差，不擅自改写为百分比。无法核验同期量时只报半日金额，删除放量/缩量判断。

数据冲突时先对齐日期、时间、范围与单位，不无条件偏向工具或媒体。仍无法解释则标明差异并收缩结论，不能拼成统一快照。

## 午盘口径与降级

- 当前封板与盘中触板不同；连板高度是午盘暂时状态，不是收盘最终晋级。炸板率或晋级率须有明确统计范围、时点和分母，不能从部分清单估算。
- 不用当日龙虎榜或历史股通席位替代上午北向资金流，不强制填充外资、游资等身份归因。资金流无可靠口径时省略。
- 午间消息与上午事件分开；午后或历史补跑不得引入目标日 13:00 之后发布的信息解释上午。
- 暂时连接失败最多重试一次，再切换当前可用来源。未知工具不反复猜名称，不要求环境必须提供 ToolSearch 或名为 WebSearch 的工具。
- 核心指数与广度都不可核验时输出数据不足说明；其他非关键指标缺失时省略对应分析，不为填模板增加无关调用。
