# 数据源参考（ashare-midday-brief）

执行窗口：交易日 11:30–13:00（午间收盘后）。优先 `westock-mcp`（腾讯自选股），辅以 `tdx-connector`（通达信）。

## 工具调用清单（A–D 步骤可并行批量调用）

### 步骤 A — 指数与量能

| 工具 | 参数 | 说明 |
|------|------|------|
| `data_market_overview` | `type=all` | 一次返回 8 组：summary 市场画像 / trade 指数开高低收 + 成交额 vs 5/10/20/60 日均值比 / interval 区间涨跌 / technical MA·BOLL·MACD·RSI·KDJ（支撑压力位）/ updown 涨跌分布（涨跌家数、涨停跌停数）/ margin 两融（常空）/ valuation 估值 / rotation 风格轮动 |
| `data_quote` | `codes=sh000688,bj899050` | 科创50/北证50（all 接口不含） |
| `data_quote` | `codes=sh000001,sz399001,sz399006` | 三大指数备用（all 接口异常时） |
| `tdx_quotes` | 指数代码 | 通达信实时行情补充/交叉验证 |

**字段**：`price`(现价)、`prev_close`(昨收)、`change_percent`(涨跌幅)、`change`(涨跌额)、`amount`(成交额)。

⚠️ **半日成交额 vs 昨日同期**：`data_market_overview` 的 trade 组是"成交额 vs N 日均值"口径，**不是**"较昨日同期"。同比数据用 WebSearch：

| 工具 | 查询词 | 说明 |
|------|--------|------|
| `WebSearch` | `A股午评 财联社 {date}` | 财联社午报一次性给出三大指数半日涨跌、两市半日成交额、较昨日同期放量/缩量幅度、上涨/下跌家数、涨停家数与连板数——**午评最重要的单一数据源** |
| `WebSearch` | `A股 半日成交 放量 缩量 {date}` | 备用交叉验证 |

### 步骤 B — 情绪指标

| 工具 | 参数 | 说明 |
|------|------|------|
| `tdx_screener` | `message=连板, pageSize=20` | 连板成分股（实时口径），判断连板梯队/情绪高度；返回家数少即连板断层 |
| `data_market_overview` | type=all 的 updown 组 | 涨停/跌停家数（盘中口径） |
| `WebSearch` | `A股 涨停 炸板 上午 {日期}` | 炸板率、高位股反馈、昨日强势股溢价——工具拿不到，财联社/开盘啦口径的午评有 |

### 步骤 C — 板块与主线

| 工具 | 参数 | 说明 |
|------|------|------|
| `data_hot` | `kind=board` | 板块实时热度排名（带涨跌幅） |
| `data_sector` | `mode=list, scope=sw1` | 申万一级行业半日涨跌幅 |
| `data_sector` | `mode=search, query=题材名` | 领涨题材成分与代表股 |
| `data_stocklist` | `mode=rank` | 概念股单平均涨跌幅（可选） |
| `data_news` | `symbol=核心个股, type=3` | 主线核心个股消息（判断事件脉冲 vs 产业逻辑） |
| `WebSearch` | `A股 上午 板块 领涨 原因 {日期}` | 补充消息催化与驱动逻辑 |

### 步骤 D — 交叉验证与降级

1. 工具数据与财联社午报冲突时，**以财联社"半日 vs 昨日同期"口径为准**，文中注明口径。
2. "Connector unavailable" → 重试一次；仍失败标【未获取】继续。
3. 某指标（炸板率/晋级率）所有渠道都拿不到 → 标【未获取】，用涨停数+连板梯队定性替代，**禁止估算**。
4. 非交易日触发 → 提示今日休市，不输出午评。

## 北向资金口径说明

北向单日全市场净流入已停止逐日披露。午评若涉及外资，用 `data_lhb`（不传参数）的 `gslmr`（股通净买入个股）+ `yyb` 中 hgt/sgt 席位动向替代表述，并注明口径。午评篇幅有限，通常可省略此项。

## 常见问题

1. **午间成交额是半日口径**：所有成交额表述必须写"半日成交"，勿写成"成交额"（易被误读为全日）。
2. **涨跌家数盘中口径**：11:30 截面即半日截面，直接引用，标注"截至午间收盘"。
3. **板块半日涨幅波动大**：领涨板块午前尾盘（11:00–11:30）可能冲高，拆解时注意"尾盘是否走弱"这一信号，财联社午报通常有提及。
