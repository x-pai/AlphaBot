# 08:30 盘前日报模板与标注规范（ashare-daily-review）

本文件保留九段式分析，定义盘前日报的每个段落该写什么、怎么标注，以及行动建议的三要素格式。
SKILL.md 第 4 节规定顺序，此处给逐段"必含字段 + 标注示例"。

---

## 日期与示例口径

T 为标题所指的今日 A 股交易日；P 为 T 之前最近一个 A 股交易日。正文注明信息截止 T 08:30（Asia/Shanghai）、实际生成时间、A 股行情基准 P。历史底盘、资金、题材、连板和日内时间线属于 P；隔夜及日韩早盘各标实际时点；今日动作全部是待验证计划。

保留全部分析模块与图表，不设固定字数上限。下面沿用的具体股票、行情与阈值均为旧版写法示例，本次未核验，不可当作目标日事实或默认策略参数；成稿须用本次有效数据替换。因资料缺失不能完成的部分注明缺口，不编造、不整段无声删去。

首页在仪表盘前写一行 **今日核心判断：P 的市场/情绪状态 → 隔夜修正 → 今日大盘路径、板块优先级和进攻程度**，附置信度及最强反证；第 7 段按大盘、板块、板块内个股展开判断先行四件套。

## 行文与判断层级

- 沿用原模板的判断先行、短句、精确数据、具名打法和认错红线。正文直接写结论与依据，不写“我们需要关注”“这说明要验证”“这样用户就能”等讲解性过渡；“关注、承接、放量、走强”不能单独充当执行条件。
- 分析顺序：P 全市场与各方向比较 → 隔夜增量修正 → 今日大盘判断 → 板块排序 → 板块内个股。首页先展示最终判断，正文按上述层级给证据。不能先挑一个消息或个股，再倒推为全市场主线。
- 第 3 段比较昨日重要方向，赋予稳定编号 B1、B2…；第 7 段先写市场 M0，再按优先级逐个写板块及其 S1.1、S1.2… 个股。编号按所属板块关联，重排优先级不改编号。大盘、板块、个股不得混排成同一层表格。
- 第 7 段承载完整判断、证据、置信度、执行条件和失效动作；第 8 段按编号汇总风险范围与仓位约束，第 9 段按编号排验证时点。三段共用同一判断，不另造观点，不重复抄行情。
- “依据≤3行”约束每个判断的直接依据，“执行方向≤3条”约束主攻与备选数量，不限制全市场扫描和昨日板块比较。资料缺失只降级相关判断，不用单一板块代替整份日报。

## 全局标注规则（贯穿全文）

每一条实质陈述前打标签：
- `【事实】`：工具返回或可核验公开数据/公告原文。例：`【事实】涨停 84 只（data_changedist）。`
- `【推断】`：基于事实的推导，附依据。例：`【推断】成交环比 -432 亿且普涨 → 缩量反弹（依据：changedist 量价结构）。`
- `【假设·待验证】`：对今日开盘后/因果的猜测，必附验证条件。例：`【假设·待验证】医药主线延续；验证：今日医药出现≥2只2连板。`（验证信号须可观察、可证伪）

消息归因段每条结尾追加因果标记：`[因果:已验证]`（price action 确认）、`[因果:未验证]`（仅消息、盘面未确认）、`[因果:未知]`。

## 1. 市场状态 · 盘面全景
必含：
- 主要指数涨跌幅（**精确值来自 `data_quote`，codes=sh000001,sz399001,sz399006,sh000688,bj899050**；报点位+涨跌幅，如"上证指数收报 3903.72 点，涨 0.24%"）。
- 成交额 + 环比（放大/缩小）。
- 涨跌家数、涨停/跌停数。
- 量价定性一句话（普涨/分化/退潮/冰点/修复）。
- **外围市场（必含，工具见 `data_sources.md`）**：美股 `usIXIC`/`usDJI` 最近常规收盘，`usSPY` 明确为 ETF，逐项写美国交易日期；港股 `hkHSI` 为最近收盘。日本/韩国以已核验指数身份取得截至 T 08:30 的早盘行情，分别标实际时点、延迟/休市/缺失。可用的美股期货/夜盘、黄金/原油/铜、DXY/CNH 分开标交易时段与报价基准。
- 一句话外围定性：隔夜及日韩反馈如何支持或削弱今日 A 股方向，标【推断】，今日是否兑现待验证。
示例（外围段，接在市场状态后）：
> 【事实】美股最近常规收盘（旧示例数值，成稿填实际美国交易日期）：纳指 usIXIC -0.66%、道指 usDJI -0.66%、标普代表 usSPY -0.31%（data_quote）。
> 【事实】港股恒生指数最近收盘 +0.80%（data_quote hkHSI）。
> 【事实】COMEX 黄金 fuGC 4545.4（+0.3%），原油 fuCL、【铜】fuHG【视实返】（data_futures）。
> 【事实】美元指数 99.11（-0.03%），离岸人民币 6.7182（data_quote fxDINIW,fxCNH）。
> 【推断】美股最近收盘偏弱但港股收涨、黄金走强，外围对 A 股贵金属/医药避险逻辑仍有支撑，对科技股指引偏中性。
示例：
> 【事实】上证指数收报 3903.72 点（+0.24%），深证成指 13972.78 点（+0.59%），创业板指 3495.59 点（+0.64%），科创50 1652.97 点（-0.87%），北证50 1081.58 点（-0.06%）（data_quote）。

## 3. 主线题材 · 谁在领涨

先用同一供应商、同一行业分类扫描 P 的全市场板块，再补充概念/题材；核验分页与覆盖范围，不能把热榜或涨幅前几名当全市场。行业与概念标明类别，重叠成分不重复计为独立主线或资金共振。

比较范围包含 P 的领涨及持续强势方向、逆势/防御方向、主要领跌及可能修复方向、隔夜新增催化方向；分类可以重叠，缺少某类事实不硬凑。昨日有多个重要方向时逐项保留；仅一条进入主攻时，其他重要方向仍写清备选、观察或回避理由。

**昨日结构 → 今日排序表**（按今日优先级排列，B 编号供第 7–9 段复用）：

| 编号 / 方向（行业或题材） | P 表现与持续性 | 板块内部与资金 | 隔夜增量 / 主要反证 | 今日定位 / 理由 |
|---|---|---|---|---|
| B1 / [实际方向] | [P涨跌幅、截至P近5日表现；缺项注明] | [上涨家数/成分总数、成交变化、核心/中军/后排、可核验资金口径] | [政策/产业/公司/海外的新增信息，或无新增；相反证据] | [主攻/备选/观察/回避，说明为何排在其他方向之前] |

- 不按单日涨幅机械排序。结合持续性、扩散、成交与资金、催化是否新增、反证比较；领涨代表和题材平均涨幅保留，单只涨停不能证明板块扩散。
- 政策背景、已公开旧消息与隔夜增量分开；政策额度不当作已入市资金，海外上涨不当作国内资金回流，板块上涨不当作净流入。
- 表内事实带来源与统计日；具体判断及置信度在第 7 段对应 B 条目展开。尚不能核验的排序标为观察，不填虚假评分。

## 4. 消息归因 · 消息与盘面互证

**按事件发布时间分两组，保留同一交叉验证方法：**
- P 交易前/盘中已公开的事件，可以对照 P 的真实盘面；“已验证”只表示价格响应匹配，不证明唯一因果。
- P 收盘后至 T 信息截止的新增事件，写“今日 A 股待验证”；海外响应单独注明市场，不能拿 P 的 A 股表现反向验证后来的消息。
- 两组均覆盖政策、产业/公司、媒体/情绪、海外；保留理论传导、实际反馈/当前缺口、匹配度及背离解释。新增事件补一列今日确认条件。

用 Markdown 表格替代逐条罗列，强制"理论是否落地盘面"。列定义：
- **新闻事件**：来源 + 时间（data_hot news / data_news / data_notice / data_calendar / data_macro）。
- **理论传导**：该消息按常识应影响的板块与方向（偏多/偏空）。
- **实际盘面**：该板块/个股 P 的真实表现；隔夜新增事件则填“今日 A 股待验证”（来自 data_sector / data_quote / data_hot）。
- **匹配度**：`[已验证]`（price action 确认）/ `[未验证]`（仅消息、盘面未确认）/ `[背离]`（实际与理论相反）。
- **背离原因（推断）**：若背离，写清其他驱动（资金/技术/情绪/其他消息），标注 `【推断】`。

矩阵示例：
| 新闻事件 | 理论传导 | 实际盘面 | 匹配度 | 背离原因（推断） |
|---|---|---|---|---|
| mRNA 突破+创新药两大利好(证券时报) | 医药 偏多 | 创新药 +6.46%、20cm 涨停潮 | [已验证] | — |
| 晶圆代工涨价15%(证券时报) | 半导体 偏多 | 半导体 -0.36% | [未验证] | 利好兑现/资金分歧【推断】 |
| 沪八条 城市更新(上观) | 地产 偏多 | 房地产开发 +1.11% | [已验证] | — |
| 商务部回应关税摩擦(新华社) | 出口链 偏空 | A股未显著反应 | [背离] | 外围噪音，内需主导【推断】 |

> 严禁"出消息=涨/跌"直推；凡未经验证的消息不得作为行情原因。

## 5. 情绪周期 · 情绪温度计

保留涨跌停、龙虎榜、真实连板分布与雁阵图，定位 **P 收盘阶段 → 隔夜修正 → 今日演化假设**。今日修复、断板、晋级均未发生。查 P 的具体日期并核验返回，不使用 08:30 的“今日涨停”占位结果。
必含：
- 涨跌停板数据（见 §1）。
- 龙虎榜（data_lhb）：机构(jg)净买/净卖居前、游资(yyb)核心席位、北向(hgt/sgt)方向、合力/分歧信号。
- **连板雁阵图**（图文，见下方规范）。

## Markdown 报告交付规范

- 标准 `.md` 文件，九个 `##` 二级标题分段，纯文本（可二次编辑、归档、转 HTML/PDF）。
- 顶部：`# 标题 + 日期`，副行注明数据来源与免责提示。
- 三类标签以行首 `【事实】`/`【推断】`/`【假设·待验证】` 标注；消息归因每条末尾 `[因果:已验证/未验证/未知]`。
- 第 5 段情绪周期内嵌 Markdown 雁阵图（见上）。
- 第 7 段按 M0 大盘 → B 板块 → S 个股呈现判断先行四件套；第 8 段汇总同编号风险，第 9 段按时点核验同一计划，禁止三段各说一套。
- 末尾固定免责声明。

## 7. 盘前思路 · 今日作战计划（全报告的行动核心）

**判断先行四件套：核心判断 → 直接依据 → 分板块具名打法 → 认错红线。** 第一行给主判断，不用高开/平开/低开全覆盖替代观点。依次输出 M0 大盘、B 板块、该板块下的 S 个股；第 3 段的重要方向必须有去向，主攻与备选执行方向合计最多 3 条，观察/回避方向各用一句交代理由。

### 判断、证据和置信度

- **M0 大盘**：P 量价广度、权重/成长关系与情绪阶段 → 隔夜修正 → 今日指数路径、风格及进攻程度。市场上涨不自动代表所有板块可做；阶段依据不足写“情绪阶段未确认”，不强套冰点/退潮。
- **每个 B 板块**：在 M0 的约束下，明确今日预期为延续、分歧、修复、退潮或新催化待兑现，给主攻/备选/观察/回避排序及比较理由。板块主张必须同时交代 P 表现、隔夜是否改变预期、确认与失效信号。
- **每个 S 个股**：放在所属 B 条目内，列名称、代码、题材、角色（核心/中军/弹性/接力）和自身预期。接力股核验连续板位或 N 天 M 板；趋势股核验量价、流动性、相对板块表现与公告，不强行编板位。每个主攻/备选方向选 1–2 只证据完整的代表，说明选它而非同板块其他候选的直接依据；无合格个股就降级观察。
- 每个 M/B/S 判断各附 **≤3 行直接依据**，格式为“【事实】[证据类别：政策/产业/公司/资金/量价/情绪/海外之一] [数据或原文要点，来源、统计/发布时间] → 【推断】[支持何种判断]”；再用一句列最强反证或关键缺口。只列实际起作用的类别，不为凑类别堆消息。同一消息转载、股价上涨与由它计算的指标不能算独立证据。
- 每层单独给 **置信度：高/中/低 + 一句原因**。高：多项独立依据一致、P 的相关结构已经形成且无重大未解反证；中：有直接依据，但催化尚待 A 股确认或证据有分歧；低：依赖单一映射、关键数据缺失或反证占优。置信度针对写明的判断，不是资料真实性或收益概率；父层评级不自动传给子层，不编百分比胜率。只有海外映射或未经兑现的消息，不能给“今日主线成立”高置信度。

### 执行条件必须可检查

- 每条 M/B/S 写明：**验证时点 + 对象/指标 + 比较基准/阈值 + 成立后的动作；失效信号 + 影响范围 + 撤销/减仓动作**。只留一组必要确认和一条主要反证，不展开所有开盘情形。
- “放量”写与 P 同时段相比的成交额及阈值；“强于板块”写个股涨跌幅减所属板块涨跌幅及门槛；“站稳”写价格基准与连续分钟数/采样次数；“扩散”写同一成分池的上涨占比或明确的核心组合。分钟数据/成分范围不可得时替换成可获取指标，不能仍宣称已验证。
- P 高低点、均线、历史成交额等基准须有本次数据，注明日期和复权口径。盘中才形成的基准写成规则（如首 15 分钟低点），不预填价格。自定持续时长、相对强度门槛等注明“策略参数”及采用理由，未经回测不称最优；不照搬示例中的比例和价位。
- 个股执行需同时满足市场风险约束、所属板块条件和个股条件，分别引用 M0/B/S 编号；无量成交、一字封板等不可成交状态不记为已执行。时点前条件未触发只记待验证，不能靠事后改阈值证明判断命中。
- **仓位统一以账户净资产占比表示，指交易后的上限，不是新增额度。** M0 给总仓上限，B 给板块上限，S 给单股上限；单股 ≤ 板块 ≤ 总仓，同一股票只计一次。板块可同时执行的预算之和不得超过总仓，有多题材归属时指定一个预算归属并注明相关暴露。上限引用用户风险预算或明确采用的策略参数；缺预算或关键执行数据时只输出观察条件，不虚填仓位或买卖数量。无实际持仓不能声称需要卖出多少。

### 成稿格式（填写真实数据，不输出填写说明）

**M0 核心判断：【假设·待验证】[P情绪/风格 → 今日大盘路径与进攻程度]；置信度：[等级及原因]。**
依据：[最多3行，每行事实、来源与推断对应；末行写主要反证]。
执行：[时点、指标、基准、阈值 → 动作]；红线：[可核验信号 → 全市场风险动作]；总仓上限：[预算依据；无依据为观察]。

**B1 [板块名]｜[主攻/备选]｜【假设·待验证】[今日预期]｜置信度：[等级及原因]**
依据：[P结构 + 隔夜增量，注明证据类别、来源；反证或缺口]。
确认：[时点、板块指标、基准与阈值]；失效：[信号 → 该板块计划调整]；板块上限：[预算依据]。

- **S1.1 [名称（代码）·角色/实际板位]**：【假设·待验证】[个股路径]；置信度：[等级及原因]。依据：[个股量价/资金/公告及与同板块候选的比较，反证]。
  执行：[M0/B1有效 + 个股时点、指标、阈值 → 动作]；失效：[信号 → 撤销该股计划/已有仓位处理]；单股上限：[预算依据]。

**B2 [另一板块名]｜[主攻/备选]**：同结构；其个股使用 S2.1、S2.2，不能挂在 B1 下。
**其他方向**：[B编号、名称、观察/回避 + 直接理由；若有升级观察条件写明时点与指标]。

下列情绪映射保留用于选择打法；趋势中军与连板接力分别分析，不能用单只接力股断板替代市场级失效信号。

**情绪周期 × 打法映射表（策略参考，非自动仓位指令）**

先依据 P 的有效数据定位阶段，再用隔夜增量更新今日假设，开盘后确认。表内数值是原策略参考阈值，不是今日行情；晋级率必须有可核验分母。仓位上限沿用时明确标为策略参数，并结合已有风险预算，不能伪装为市场数据算出的精确比例。

| 阶段 | 识别特征（步骤 E 数据可核验） | 打法定性 |
|---|---|---|
| 冰点 | 涨停 <30、最高板 ≤2、晋级率 <20%、跌停数逼近涨停 | **不碰连板**；空仓或超跌低吸，总仓 ≤20% |
| 修复 | 涨停回升 40–60、首板蜂群重现、高度止跌于 2–3 | 轻仓试错**首板**（不接高度），总仓 ≤30% |
| 发酵 | 梯队重新完整、晋级率 >50%、放量、高度 4+ | 打**中位晋级位**（2→3、3→4），宽度高度皆可 |
| 高潮 | 涨停 80+、最高标缩量加速、晋级率 >70% | **只持股不加仓**；高位兑现，打宽度不打高度 |
| 分歧 | 高位放量炸板增多、晋级率骤降、换手板多 | 只打**换手回封龙头**或低吸核心，不追一致加速 |
| 退潮 | 高度股集体断板、跌停数放大、梯队自上而下断层 | **只卖不买**，空仓等待冰点信号 |

阶段缺少关键证据时不强行归类；表中仓位和阈值仅为原策略参考，须满足上文预算与参数说明规则才可采用。

## 10. 上一交易日时间线（保留个性化五模块，报告尾部）

本节的标签、形状、轨迹、名场面和时段节点全部属于 P，标题写明 P 的实际日期；分时必须能还原 P。随后另列 P 收盘至 T 信息截止的隔夜消息、美国常规收盘、日韩早盘节点，用来解释今日开盘前判断如何更新。

目标：让每天的时间线具有**独特辨识度**——读标签即知上一交易日性格，读名场面即记上一交易日高潮。五个子模块：
