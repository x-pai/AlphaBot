# 盘前日报数据来源（westock → WebSearch，采集口径 v2）

接口经验依据：用户提供的《AlphaBot 盘前日报 · 数据采集修正 Prompt（v2）》，测试日期 **2026-11-06**；其中市场级两融空表的测试区间为 2026-10-30 至 2026-11-05。这是已有回归记录，不代表每次生成时已重新实测。参数遵循当前暴露的 schema；已知缺失项按下文跳过，仅在连接/版本变更或用户要求复测时重新验证并更新记录。

## 1. 时间、回显和状态

T 为目标 A 股交易日，P 为之前最近一个交易日，截止 T 08:30（Asia/Shanghai；提前版取实际时间）。使用交易日历确认 T/P；美股、港股、日韩各自确认交易日。westock 的 `date` 在已有测试中为“最近可用日”语义：未来日、周末、未披露日可能静默回退，成功响应不等于请求日期命中。

- 每次核对响应级、`data.date`、子表级及逐证券的实际日期；总览各子表不能沿用外层日期。子表缺日期且无法另证时，注明无法核验，不臆测与其他表同日。
- A 股底盘只使用 P 已完成行情；08:30的清零/占位、实时查询日期、热度榜都不能当作 P 收盘结果。统计月份早于截止也不等于发布日期早于截止。
- 保存字段名、原始值、单位、范围、实际日期/时点、来源、`notice`、`isDelayed`；取数与单位换算可追溯，成稿引用不能凭记忆或上一轮会话复述。

### 数据状态与日期

数据状态与【事实】【推断】【假设·待验证】分开标注。T 为目标交易日，P 为 T 之前最近交易日；本模板的 T-1 均指 P，不是自然日。每个引用行/表格行附实际日期，不能只在文首写一次截止时间。

| 状态 | 使用条件与必填信息 |
|---|---|
| 【已获取·T-1】 | 返回实际日期为 P，写 P 的具体日期；估值/两融不能按接口名称自动归入此类 |
| 【已获取】 | 已取得符合截止边界的数据，写行情日期、实际时点及交易时段；更早的最近收盘另标“最近收盘/滞后”，不当作 P 或今日行情 |
| 【接口无数据】 | 已有记录证实该接口/listCode结构性无数据；注明接口及确认日期，跳过日常重试；一次空表不能自行升级为结构性缺失 |
| 【尚未披露】 | `notice` 或官方发布安排明确请求统计日尚未披露；保留原文，另写实际返回的最近披露日和值；不能固定假设滞后一天 |
| 【无官方数据】 | 官方已停止披露该指标，注明替代口径和制度来源；不得拿供应商估算冒充官方数据 |
| 【未获取】 | 临时失败或当前渠道无法核验，列尝试渠道及原因；空表、403、休市、尚未披露不能一律解释成零值或市场偏弱 |

请求日、返回统计日、行情时点、发布时间和请求时间分别记录。请求 P 却返回更早日期时，所有引用处标实际日期并标滞后；不能用于确认 P 的情绪/梯队/板块排序。返回晚于截止的行情或截止后才披露的数据直接排除。历史补跑仅有统计日期、无法确认当时已公开的数据也不能补进盘前快照。

## 2. 指数、个股与汇率：data_quote

`codes` 逗号分隔批量请求，证券名称/代码/市场必须与返回逐项对应；未返回的代码单独标缺口，不拼凑报价。

| 用途 | 已有代码线索 | 核验重点 |
|---|---|---|
| A股大盘/风格 | sh000001,sz399001,sz399006,sh000688,sh000300,sh000016,sz399905；北证50 bj899050按需核验 | P收盘价、涨跌幅、时点；沪深300、上证50、中证500按实际返回身份引用 |
| 港股 | hkHSI | 恒生指数最近常规收盘，标香港交易日期；不是恒生科技 |
| 美股 | usDJI,us.NDX | 道指、**纳斯达克100**；us.NDX不能写成纳斯达克综指，也不能代替标普500 |
| 补充美股 | usIXIC/usSPY/usQQQ仅在当前schema及返回身份验证后使用 | 分别为纳斯达克综指/标普500 ETF/纳指100 ETF；ETF价格不能当指数点位；缺指数时用WebSearch收盘报道或标缺口 |
| 汇率 | fxDINIW,fxCNH | 美元指数、离岸人民币，币对方向与报价时点核验；人民币中间价不能代替CNH即期 |

## 3. 股指期货、商品与日韩早盘

- `data_futures(mode=quote)`：纳指100期货 **fuNQ**、标普500期货 **fuES**、COMEX黄金 **fuGC**、WTI **fuCL**、布伦特 **hf_OIL**；铜 fuHG 按需核验。按实际 schema 的 code/codes 传参，保留合约身份、币种/单位、比较基准、时间戳和 `isDelayed`；不能因hf前缀就假设所有原油通用同一代码。
- 每个期货引用行写实际报价时点与延迟状态；`isDelayed=true` 写“延迟”，字段缺失写“延迟状态未提供”，不能默认为实时。超过截止的最新价不进入盘前报告；旧报价写最近可得及其时点，不按请求时间刷新。
- 盘前新增冲击优先观察有效时点的股指期货，并保留现货最近收盘背景。**期货与现货是不同品种、时段和比较基准，方向相反时并列说明，不能按时间戳较新者覆盖另一项。** 只有同品种、同基准、同口径且截止内的报价，才按实际时点比较新旧。
- 日韩：2026-11-06记录中 `data_search(jpkr_market=jp/kr)` 返回403，日常跳过该失败路径，直接 WebSearch 获取日经/TOPIX/KOSPI/KOSDAQ 早盘。优先交易所/指数提供商，其次可靠媒体；读取正文核对市场身份、北京时间、延迟/休市，只取得08:00开盘数据就不能写成08:30快照。失败写【未获取】及已尝试渠道，不把403定为永久停披露。
- 北京时间08:30不是美股常规盘前。港股只用最近收盘；日韩正常交易日当地09:00为北京时间08:00，交易时段/节假日以目标日期核验。

## 4. 市场总览与交叉核对

默认一次 `data_market_overview(type=all, date=P)`，复用返回的 summary / trade / interval / technical / updown / margin / valuation / rotation，**逐表核对 data.date**。valuation 在已有测试中滞后，实际引用仍以该表回显为准，不固定写某个相对日期。

| 表 | 使用字段/含义 | 限制 |
|---|---|---|
| trade | 指数开高低收、MONEY、相对5/10/20/60/120/250日均量的占比 | 均量占比不是历史分位；逐行确认指数/全市场范围，不能把多个指数成交额重叠相加 |
| updown | 涨跌家数、涨跌停、创新高/新低家数 | 记录市场范围、ST/新股等规则；不能从媒体数字替换部分字段后继续同口径计算 |
| summary | 九维画像，保留实际返回维度和分数 | 作为量化参考；与原始统计冲突先核对日期和定义，不自行补维度或分数 |
| rotation | 沪深300、成长/价值、中证1000等实际返回的多周期表现 | 同日期/窗口比较风格，不把指数上涨当资金净流入 |
| valuation | 估值表 | 按子表实际日期标滞后，不假定与trade同日 |
| margin | market_statis_margin_chg，已知服务端无数据 | 标【接口无数据】；all响应中的空表跳过，**禁用type=margin单独重试** |

`data_changedist(type=0)` 对照 P 的宽度、成交额与涨跌停，核验实际日期；若返回今日占位或盘中数据，不参与 P 的全日核对。

**成稿前核验：**
- 成交额：`trade.MONEY`、`data_changedist`、可靠媒体（优先财联社）三方比对，先统一交易日、范围、单位。以已确认同口径的 trade.MONEY 为基准，绝对差 / 基准 >1% 时并列实际值与差异；范围不一致先标范围，基准为0/缺失不计算差率。已有测试一致不代表今后免核验，不平均或估算修正；缺一方写来源缺口。
- 涨跌停：**westock updown 与财联社两口径并列**，各写日期/范围/来源。差异若无已核验规则解释，写“口径差异，判定规则待核验”，不能猜原因。媒体不可得时保留接口值并标媒体口径【未获取】；不得凑第二组数。首板/晋级率使用同范围完整池，不能从混合口径作差。
- 多源冲突：日期与范围一致后优先原始接口/交易所数据；接口陈旧或错期不因“一手”而优先。价格、资金、两融等保留原始字段值与换算单位，旧示例不能带入本次报告。

## 5. 两融、龙虎榜和北向代理

### 两融：data_fund_margin

- 个股唯一入口 `data_fund_margin(codes=当日实际候选, date=P)`；当前 schema 只支持单股时用 `code`。**不能只传date**，市场级余额不能用个股求和代替。候选按实际梯队/异动/主攻板块更新，不固定使用测试股票清单。
- 请求P后读取 `notice` 原文和实际返回日期。若notice说明尚未披露，写【尚未披露】、请求日、最近已披露日与替代数据；返回较早日期但无披露说明时只标滞后，不自行推定披露制度。`notice`与数据日期相互矛盾时标冲突并暂停该判断。不固定写“T-1/T-2已披露”。
- 对融资标的候选以 `start/end`（支持时）查截至最近已披露日的近10个交易日，关注 `FinanceValue`、`FinanceValueDOD`，检查是否纳入融资名单及字段单位。`FinanceValueDOD >50%` 是本技能采用的**杠杆异动筛查阈值**，不是买入信号；确认DOD是百分数还是小数后比较，同时列余额绝对值、前期基数与数据日，防止低基数误读。缺字段不按0处理。
- 原始值例如以元提供，换算亿元为原值/100000000；关键数字附字段名及原始值或可回查的来源。不能把融资余额变化叫当日主力资金净流入。

### 龙虎榜：同一响应复用

`data_lhb(type=yyb, date=P)` 优先取营业部席位榜及对应个股，同一次响应中分离普通营业部、机构专用、沪股通专用/深股通专用。核验字段、统计窗口、分页与覆盖后复用到机构/游资/北向代理段，不默认任一Top N响应含全部三类；缺类才按当前schema补查询或标缺口。机构专用与股通席位不混入普通游资统计，同一记录按证券、席位、统计区间及上榜事由去重，1日榜和3日榜不重复求和。

### 北向席位动向（代理口径）

- **不再采集北向全市场净流入/净买入**，该项目标【无官方数据】。交易所自2024-08-19调整披露后，北向日终公布成交总额等，不能据总成交额反推净买入；南向披露规则不能移植到北向。
- 用龙虎榜“沪股通专用”“深股通专用”已实际披露的席位净买卖，固定表述为“北向席位动向（代理口径）”，列具体个股、统计日和覆盖范围。它只代表上榜样本，不能改写为全市场“北向净买入”，不外推板块总流向；样本未出现不等于净买入为0。
- `data_north_holding` 如补充，仅作实际披露期的持股结构背景；季度数据不当日更，也不从持仓差反推每日流入。
- 制度依据：[上交所上证发〔2024〕106号](https://www.sse.com.cn/lawandrules/sselawsrules2025/global/hkexsc/c/c_20250613_10781806.shtml)、[深交所深证上〔2024〕601号](https://www.szse.cn/szhk/hkbussiness/news/t20240726_608353.html)。

## 6. 板块与个股：价格、资金、梯队互证

- `data_sector(kind=industry, mode=ranking, type=changePct, order=desc, limit=15)` 与 `type=mainNetInflow` 各取一份并按同一板块身份对齐；查领跌/流出端时用schema支持的升序/分页/扩大范围，不凭Top15宣称全市场。mode=list/search等仅在当前schema支持时用于目录/成分，不沿用旧的scope=sw1排名调用。
- 第3段每个重要板块同时列 **价格（涨幅/广度）、资金（板块主力净流入/出）、梯队（连续板位/核心中军后排）** 三列。价涨资流出、价跌资流入、领涨却梯队断层均点名；缺证据按状态标缺口，降低相应置信度，不能用上涨代替资金证据。趋势板块无接力梯队时说明真实结构，不为凑齐强造连板。
- `data_hot(board/stock)`、`data_stocklist(rank/detail)`补热度与成分，热度不等于强度；`data_fund_flow(codes=候选)`核验个股资金，个股样本不代表板块资金总额。
- 连板用 `tool_ranking(asset=stock, metric=limitup_days, date=P, order=desc, limit=50)`，检查实际日期、总量和分页；按需补limitup_seal_volume。N天M板由 `data_finsearch`/可靠报道回查来源与发布时间，不与连续连板混同。
- 新闻、资金与梯队日期不同则并列，旧数据只作背景；今日开盘后的主线成立与晋级仍是待验证假设。

## 7. 消息、日历与采集时序

- 资讯使用 `data_flash_news_search` + WebSearch，覆盖宏观/政策、地缘、大宗、板块/公司等至少3类主题的检索；报告只保留改变判断的事件，未命中不凑新闻。`domain_search`仅补产业/政策背景，不用作行情数字来源。
- `data_calendar` 在2026-11-06测试中仅返回日期序列，**不能当财经事件明细**；只有明确标为相应市场交易日历的返回才能用于确认T/P，普通日期序列不能当交易日历。今日政策/数据发布日程用快讯检索及WebSearch回查发布机构/官方日历，注明时区；不能从一串日期编事件。
- 个股 `data_news(symbol=实际候选, type=3)` / `data_notice` 核验公告原文与首次公开时间；`data_hot(news)`用于发现线索。`data_macro`按实际schema取已公布指标与预期，统计期、发布时间分开；截止后公布的实际值不可用。
- 消息窗口 P 收盘至T截止，长假覆盖整个间隔；P盘中已有消息用于P归因，隔夜新增信息仅写今日待验证，旧新闻重新传播不算新增催化。研报和AI摘要属于线索/观点，回查原文。

参考采集顺序：07:00–07:30隔夜现货/期货/汇率 → 08:00–08:20日韩早盘及行业映射 → 08:00–08:25快讯与候选公告 → 截稿前补齐P总览、龙虎榜、个股两融并校验日期。它是数据阶段安排，不要求新增调度任务或等待到这些时点；单次08:30任务可批量取数，但仍只接受截止内快照和当时已公开的信息。午报按M0/B/S编号用盘中行情验证，不倒填盘前数据。

## 8. 兜底与已知缺失

默认顺序 **westock → WebSearch**；WebSearch优先原始发布机构/交易所，再用可信媒体，明确来源名称、原文链接、信息时点及“非接口一手数据”。本版本不自动转通达信；用户明确指定仅通达信时使用独立的 `ashare-daily-review-tdx`。

| 项目 | 2026-11-06记录/制度状态 | 日常处理 |
|---|---|---|
| market_statis_margin_chg / overview.margin | 2026-10-30至11-05均空 | 【接口无数据】，不单独调用type=margin；只用个股两融，不能替代市场总余额 |
| data_search(jpkr_market=jp/kr) | 403 | 跳过失败路径，WebSearch兜底；检索失败列渠道与原因 |
| data_calendar事件明细 | 仅日期序列 | 直接快讯/WebSearch核验事件，不反复调用期待明细 |
| 北向全市场净买入 | 官方停止原口径披露 | 【无官方数据】，用龙虎榜北向席位代理 |
| data_forex(mode=quote) | 无有效报价、仅清单 | 改用data_quote，不重复探测报价模式 |

其余临时连接失败重试一次后兜底；已知缺失不每天重试。关键P行情不可核验输出短报，单项缺失只收缩相关结论。接口修复有新证据时更新本表，不把某日403或空表写成永久事实。

交易时段参考：[Nasdaq](https://www.nasdaq.com/market-activity/stock-market-holiday-schedule)、[JPX](https://www.jpx.co.jp/equities/trading/domestic/01.html)、[KRX](https://regulation.krx.co.kr/contents/RGL/03/03020401/RGL03020401.jsp)。

- 资金迁徙图与分类资金表保留，区分主力估算、机构/游资席位、北向席位代理和个股融资；资金缺口按状态标注，不能用板块涨跌填流向。

- 题材平均涨幅、近月涨幅、真实连板分布与反包池继续保留；`avgChangePct`/`accChangePct1M`与晋级率各自核验窗口及完整分母。

## 10. 从板块比较到执行条件的取数

1. **比较范围**：先查 P 的完整行业范围与涨跌排名（核验分页），再查主要概念/题材；保留各方向的分类、代码和成分范围，行业与概念不混算。逐项补截至 P 的近5个交易日涨跌幅、成交额/同口径变化、成分上涨数与总数、核心/中军/后排；有资金数据再判断净流向。无法获得完整范围时写覆盖限制，不能宣称全市场只有所取的几个方向。
2. **持续性**：近5日收益使用 P 收盘 / P 前第5个交易日收盘 − 1（或明确口径的供应商字段），不是5条日线首尾直接当5日；价格复权一致。单日板块涨幅、资金估算、龙虎榜与融资分别保存来源和统计期；同一供应商派生指标不当作多份独立资金证据。
3. **候选归属**：每个主攻/备选方向分别查成分与候选，确认业务关联及核心/中军/弹性/接力角色；查询实际候选截至截止时刻的公司公告、停复牌/减持/解禁等相关事件，不能只查行业新闻。未查全就注明覆盖，不写“无风险公告”。
4. **价格与成交基准**：候选取 P 收盘、高低点、成交额及所需历史K线；比较板块与个股时统一涨跌基准和时点。计划用“10:00较昨日同时段放量”时，盘前先保存 P 09:30–10:00 累计成交额，确认分钟字段是单根还是累计、是否含竞价；无历史分钟数据就改用可取得指标，不能拿开盘半小时对比昨日全天。
5. **条件交付**：向第7段提供具体基准值、来源/日期/复权方式及可取得的盘中核验字段；今日首15分钟高低点等仅交付计算窗口，08:30不填未来数值。策略阈值另标依据；缺输入的条件降级观察。午报沿相同成分池、资金口径、比较窗口及 M0/B/S 编号核验，不能切换指标来证明原判断正确。

取数通道：`data_sector` / `data_stocklist` 核验范围与成分，`data_quote` / `data_kline` / 可还原P的分钟线核验量价基准，`data_fund_flow` / `data_lhb` 补资金，`data_news` / `data_notice` 查候选公告。参数和历史支持以本次 schema 为准。
