# 复盘报告模板与标注规范（ashare-daily-review-tdx）

本文件定义九段式复盘的每个段落该写什么、怎么标注，以及行动建议的三要素格式。
方法论与 `ashare-daily-review` 一致；数据源全部为 tdx-connector（代码/setcode 见 `data_sources.md`）。

---

## 全局标注规则（贯穿全文）

每一条实质陈述前打标签：
- `【事实】`：工具返回或可核验公开数据/公告原文。例：`【事实】涨停 49 只（tdx_screener meta.total）。`
- `【推断】`：基于事实的推导，附依据。例：`【推断】上涨 1062/下跌 1205 且缩量 → 弱分化（依据：tdx_quotes 涨跌家数字段）。`
- `【假设·待验证】`：对次日/因果的猜测，必附验证条件（可观察、可证伪）。

消息归因段每条结尾追加因果标记：`[因果:已验证]` / `[因果:未验证]` / `[因果:未知]`。

## 0. 全景速览仪表盘（报告顶部，unnumbered）

| 维度 | 当日表现 |
|---|---|
| 指数 | 上证 -0.41% / 深成 ±X% / 创业板 ±X% / 科创50 ±X% |
| 个股 | 上涨 1062+深市X / 下跌 1205+深市X（tdx_quotes 涨跌家数相加） |
| 成交额 | 沪市 8687.7 亿 + 深市 X 亿（环比 ±X 亿） |
| 涨跌停 | 涨停 49 / 跌停 X（tdx_screener meta.total） |
| 核心资产 | XX 板块领涨（tdx_screener 概念板块排名） |
| 资金面 | 主力/北向/融资方向（tdx_screener 资金面） |
| 外围 | 美股(纳指 +1.62%, setcode=12) / 恒指 -0.44%(setcode=27) / 沪金 AU X / 人民币中间价 6.7628 |

> 定性：一句话（如"缩量弱分化，情绪处于 XX 阶段"）。

## 1. 市场状态 · 盘面全景
必含：
- 主要指数涨跌幅（**精确值来自 `tdx_quotes`**：上证 000001/1、深成 399001/0、创业板 399006/0、科创50 000688/1、北证50 899050/2；报点位+涨跌幅）。
- 成交额 + 环比（tdx_quotes `Amount` 与 `Close` 字段推算；环比缺前日数据时用 `tdx_kline` period="day" 补）。
- 涨跌家数（**tdx_quotes 指数返回自带 `上涨家数/下跌家数/平家数`**，沪深相加）、涨停/跌停数（tdx_screener meta.total）。
- 量价定性一句话。
- **外围市场（必含）**：
  - 美股：`tdx_quotes`（A_IXIC/A_DJI/A_SPX, setcode="12"），盘中标"截至 HH:MM，未收盘"。
  - 港股：`tdx_quotes`（HSI, setcode="27"），标"当日收盘"。
  - 内盘大宗：`tdx_futures_quotes`（setDomain="30", subCode="AU"/"CU"/"SC"）。
  - 汇率：`wenda_macro_query`（关键词"人民币汇率中间价"）报中间价；DXY/CNH 取不到标【未获取】或 wenda_news 兜底（标媒体+时点）。
  - 一句话外围定性。
示例：
> 【事实】上证指数收报 3875.60 点（-0.41%），成交 8687.7 亿（tdx_quotes 000001/1）。
> 【事实】上涨 1062 / 下跌 1205 / 平 85（沪市，tdx_quotes 自带字段）；涨停 49（tdx_screener）。
> 【事实】美股盘中：纳指 26398.51（+1.62%）（tdx_quotes A_IXIC/12，截至复盘时刻未收盘）；恒指收盘 24604.29（-0.44%）（HSI/27）。
> 【事实】人民币中间价 6.7628（wenda_macro_query，9-16）；美元指数【未获取】（tdx 无 DXY 行情通道）。
> 【推断】外围美股偏强、港股偏弱，对次日 A 股科技线指引偏多、整体中性。

## 2. 资金结构 · 钱往哪走
必含：板块强弱（tdx_quotes 880/881 板块 / tdx_screener 板块排名）、资金流向（tdx_screener"主力净流入居前"等 + tdx_security_deep_info）、大小盘风格。
**资金轮动路径（强制 · 资金迁徙图 + 四维度资金表）**：迁徙图概括"谁流出 → 谁流入 → 驱动 → 本质"；四维表把 主力/游资/北向/融资盘 方向落到证据（tdx_screener 资金面维度 / security_deep_info 融资融券与沪深港通）。

## 3. 主线题材 · 谁在领涨
必含：最强 1–3 条主线（tdx_screener 概念板块排名 / tdx_api_data 热点题材族）、领涨代表（从涨停清单"涨停原因"归并）。
示例：`【事实】半导体/芯片题材涨停 8 只（tdx_screener 涨停清单按"涨停原因"归并）→ 当日最强主线。`

## 4. 消息归因 · 消息与盘面互证（交叉验证矩阵）
列 = 新闻事件（来源+时间，wenda_news/notice/report/macro、tdx_ai_listening）｜理论传导｜实际盘面（tdx_quotes/tdx_screener）｜匹配度[已验证/未验证/背离]｜背离原因（推断）。
> 严禁"出消息=涨/跌"直推；`tdx_ai_listening` 的多空权重可作个股级归因佐证，但其结论本身属【推断】。

## 5. 情绪周期 · 情绪温度计
必含：涨跌停（§1）、龙虎榜（tdx_screener"今日龙虎榜机构净买入居前"）、**连板雁阵图**（见下）。

### 雁阵图规范（连板高度分布表 + 文本阶梯图，真实数据）
**用 `tdx_screener` 取真实连板梯队**（message="连板", pageSize=50），禁止估算层级数量：
- 返回每只的**连续涨停天数/几天几板/板型/封单金额/涨停原因**，按连板数降序直接分层。
- **多日反包高位股**（N天M板）：screener 查不到断板反包 → `wenda_news_query`（keyword="反包"/"N天M板"）文本兜底，标注媒体来源+时点。
- 首板广度 = 涨停总数（meta.total）− 连板总数。
- 若 tdx 不可达：标【未获取】，仅列可核验项，**不得编造层级**。

**第一步：连板高度分布表（真实数量）**
| 空间高度(连板天数) | 数量 | 代表 |
|---|---|---|
| 最高板(如 3 板) | 1 | 中晶科技（半导体，T字板，开3次） |
| 2 板 | X | … |
| 首板（蜂群） | X | … |

**第二步：文本阶梯图（真实锚定 + 断层诊断）**
```
连板雁阵图（真实梯队 · tdx_screener 连板清单）
┌────────────────────────────────────────────────────┐
│ 空间高度(连板) │ 数量 │ 代表 / 板型                  │
├────────────────────────────────────────────────────┤
│ 3板(最高标)    │ 1   │ 中晶科技(半导体,T字板,开3次)  │

```

## 6. 持仓交易 · 仓位体检
- 仅当用户提供持仓或授权后填写真实数据；无数据 → "未提供持仓数据，跳过。"

## 7. 盘前思路 · 次日作战计划（全报告的行动核心）

**铁律：判断先行，宁可错、不可没有观点。** 禁止用全覆盖条件分支代替判断。格式为"判断先行四件套"，一屏内：

1. **核心判断**（一句话）：**情绪周期定位 + 方向 + 打法定性**（兑现日/上车日/分歧日/退潮日/宽度日/高度日）。
2. **依据**（≤3 行）：事实 + 推断一一对应。
3. **打法（≤3 条，必须具名）**：标的从**当日连板梯队（tdx_screener 连板清单）与反包池（wenda_news）**中选出，写明 代码+板位+题材。**"光模块低位补涨"不是打法，"中晶科技(003026) 3 板晋级位"才是**。条件只保留一条竞价确认。
4. **红线**（1 条认错信号 + 1 个总仓数字）。

**情绪周期 × 打法映射表（打法必须与阶段匹配——不是什么情绪都能做连板）**

| 阶段 | 识别特征（步骤 E 数据可核验） | 打法定性 |
|---|---|---|
| 冰点 | 涨停 <30、最高板 ≤2、晋级率 <20%、跌停数逼近涨停 | **不碰连板**；空仓或超跌低吸，总仓 ≤20% |
| 修复 | 涨停回升 40–60、首板蜂群重现、高度止跌于 2–3 | 轻仓试错**首板**（不接高度），总仓 ≤30% |
| 发酵 | 梯队重新完整、晋级率 >50%、放量、高度 4+ | 打**中位晋级位**（2→3、3→4），宽度高度皆可 |
| 高潮 | 涨停 80+、最高标缩量加速、晋级率 >70% | **只持股不加仓**；高位兑现，打宽度不打高度 |
| 分歧 | 高位放量炸板增多、晋级率骤降、换手板多 | 只打**换手回封龙头**或低吸核心，不追一致加速 |
| 退潮 | 高度股集体断板、跌停数放大、梯队自上而下断层 | **只卖不买**，空仓等待冰点信号 |

> 用法：核心判断第一步在这张表对号入座（依据 = 步骤 E 的梯队断层/晋级率/涨停跌停数/最高标量价——最高标量价用 `tdx_quotes` 或涨停清单的"板型/打开次数"判断缩量加速还是换手）；打法必须落在该阶段框架内。

**实战示例（数据为 2026-08-28 westock 版示例的 tdx 重写，工具名已替换；结构照此）**

> **核心判断：情绪定位：发酵末段、高潮信号初现（涨停 78、梯队无断层、晋级率 61.5%、最高标缩量加速）——做宽度、不做高度——算力兑现日，高位股是卖点不是买点。**
>
> 依据：
> - 【事实】梯队 6→5→4→3→2 无断层、晋级率 61.53%、放量至 2.13 万亿（tdx_screener 连板清单 + tdx_quotes 成交额）。
> - 【事实】深中华A(000017) 六板一字缩量（tdx_screener 涨停清单"板型"字段）；隔夜纳指 +1.57%（tdx_quotes A_IXIC/12），但 A 股算力昨日已放量兑现。
> - 【推断】缩量加速板 + 天量成交 = 高位筹码交换最剧烈阶段，追高度盈亏比 <1:2。
>
> 打法：
> 1. 算力宽度两只：**杭电股份(603618, 2板·算力线缆)、法尔胜(000890, 2板·光纤)** 打 3 板晋级位，竞价高开 2–5% 温和放量即介入；首板池盯 **联瑞新材(688300·PCB填料)、英特科技(301399·液冷)** 的 2 板确认，谁先板做谁。
> 2. 高度只看一只：**楚天龙(003040, 5板·数字货币)** 换手晋级是唯一出手的高度；**康盛股份(002418, 3板·液冷)** 高开 >4% 不追——兑现日卖相。
> 3. 黄金线看 **深中华A(000017, 6板)** 脸色：封 7 板则黄金低位补涨跟做；断板则连同反包池（wenda_news 检索"反包"补充）整体回避。
>
> 仓位：总仓 ≤50%；沪指高开 ≥1% 且 9:35 不回补缺口才执行第 1 条，否则全天三成观察仓。
>
> 红线：深中华A 炸板/断板 = 全场高位股风险释放信号，此后只卖不买。

> 与第 9 段联动：核心判断必须在"次日验证"清单里有对应可证伪信号，次日复盘对照自评——判断错了要认。

## 8. 风险控制 · 认错红线
- 风险红线（明确信号 → 动作）、总仓位上限、外部风险（外围暴跌/汇率异动）应对。

## 9. 次日验证 · 观察信号清单
列 2–5 个可证伪信号，次日对照自评命中率。

## 10. 全天时间线（个性化版，报告尾部）

五子模块（**今日标签与名场面每日必须不同，禁止套模板**）：

**① 今日标签**（3–6 个 hashtag）
**② 日内形状**（ASCII 轨迹 + 形状命名 + 心理关口，数据来自 `tdx_kline` period="1m"）
**③ 日内轨迹**（关键价位序列 + 故事线）
**④ 今日名场面**（一个瞬间的场景叙事）
**⑤ 时段节点表**（五列：时段/情绪/核心事件/暗流(推断)/数据来源）

| 时段 | 情绪 | 核心事件 | 暗流（推断） | 数据来源 |

## Markdown 报告交付规范

- 标准 `.md` 文件，九个 `##` 二级标题分段；顶部 `# 标题 + 日期`，副行注明数据来源（tdx-connector）与免责提示。
- 三类标签行首标注；消息归因每条末尾 `[因果:已验证/未验证/未知]`。
- 第 5 段内嵌雁阵图；第 7 段判断先行四件套；第 8 段三行格式。
- 末尾固定免责声明。
