# 盘前日报数据来源（仅 tdx-connector）

本文件保留已有通达信调用经验；本次实际 schema、返回身份与时点优先，不能把历史实测当永久可用保证。T 为目标 A 股交易日，P 为 T 之前最近一个 A 股交易日，默认截止 T 08:30（Asia/Shanghai）。

## 1. 日期和报价边界

先确认 A 股交易日历与 P，海外市场各自确认是否交易。每项数据记录来源、实际行情/发布时间、时区、范围和单位。早晨请求到的 quote 可能是旧收盘或清零占位；请求时间不等于行情时间。

延迟或历史补跑只用可还原的截止前行情、历史日线和当时已公开的消息。实时筛选、24 小时摘要和今日完整日线不能用于倒填盘前已知信息。

### 数据状态与日期

数据状态与【事实】【推断】【假设·待验证】分开标注。T 为目标交易日，P 为 T 之前最近交易日；本模板的 T-1 均指 P，不是自然日。每个引用行/表格行附实际日期，不能只在文首写一次截止时间。

| 状态 | 使用条件与必填信息 |
|---|---|
| 【已获取·T-1】 | 返回实际日期为 P，写 P 的具体日期；估值/两融不能按接口名称自动归入此类 |
| 【已获取】 | 已取得符合截止边界的数据，写行情日期、实际时点及交易时段；更早的最近收盘另标“最近收盘/滞后”，不当作 P 或今日行情 |
| 【接口无数据】 | 已有记录证实该接口/listCode结构性无数据；注明接口及确认日期，跳过日常重试；一次空表不能自行升级为结构性缺失 |
| 【尚未披露】 | `notice` 或官方发布安排明确请求统计日尚未披露；保留原文，另写实际返回的最近披露日和值；不能固定假设滞后一天 |
| 【无官方数据】 | 官方已停止披露该指标，注明替代口径和制度来源；不得拿供应商估算冒充官方数据 |
| 【未获取】 | 临时失败或当前渠道无法核验，列尝试渠道及原因；空表、403、休市、尚未披露不能一律解释成零值或市场偏弱 |

请求日、返回统计日、行情时点、发布时间和请求时间分别记录。请求 P 却返回更早日期时，所有引用处标实际日期并标滞后；不能用于确认 P 的情绪/梯队/板块排序。返回晚于截止的行情或截止后才披露的数据直接排除。历史补跑仅有统计日期、无法确认当时已公开的数据也不能补进盘前快照。

## 2. 行情与历史底盘

### tdx_quotes / tdx_lookup_stock

`tdx_quotes` 使用 code + setcode（类型按 schema）。下列是已有代码线索，返回证券名称和日期仍须核验：

| 市场 | code / setcode | 盘前用途 |
| --- | --- | --- |
| 上证 / 深成 / 创业板 | 000001 / 1、399001 / 0、399006 / 0 | P 收盘底盘 |
| 科创 50 / 北证 50 | 000688 / 1、899050 / 2 | 按需补充 P 风格 |
| 美国主要指数 | A_IXIC、A_DJI、A_SPX / 12 | 截止前最近完成的常规交易日收盘，写美国交易日期 |
| 恒生指数 | HSI / 27 | 最近收盘，不能称今日港股盘中 |
| 港股个股 | 如 00700 / 31 | 核验身份后按需使用 |

未知证券、板块、日韩指数或期货先用 `tdx_lookup_stock` 查询。既有 range 线索：AG、HK-GP、MG-GP、ZS、QH；传给后续工具的 entity_code / entity_setcode / entity_type 以实际返回为准。查询词匹配不代表实体正确，例如美元指数可能误匹配到其他指数。

- 指数附带上涨/下跌/平家数时，核验它覆盖交易所还是指数成分；不能直接相加重叠成分统计冒充全市场。
- Amount、Close、量比等字段含义以实际 schema 为准，不用价格前收字段计算成交额变化，也不把 08:30 的占位零值当成交萎缩。
- 美股 quote 若只有盘后/夜盘最新价，必须另取已完成常规收盘或省略，不把最新价强制贴成收盘。

### tdx_kline

code + setcode + period + count，周期以实际支持为准。日线用于 P 及以前的价格、趋势、均线；剔除 T 未完成/占位 K 线，核验复权和交易日期。分钟线用于还原 P 的日内形状、轨迹、关键节点与名场面，也可核验海外早盘；必须核对日期，不把 T 的序列当 P。

### tdx_screener

message + rang + pageNo/pageSize。查询中明确 **P 的具体日期**与口径，例如 P 收盘涨停、连板、板块涨幅、主力流向、龙虎榜；必须核验工具真的支持历史查询并返回 P，不能默认把“今日涨停”理解为上一交易日。

连板、几天几板、板型、封单等字段以返回为准。检查总数与分页，单页或前 50 条不代表全量，不能据此断言没有某层梯队。资金供应商估算、龙虎榜席位、披露期持股与个股融资不能互相替代。北向全市场净买入不再采集，标【无官方数据】；用沪/深股通专用席位的实际净买卖写“北向席位动向（代理口径）”，仅限上榜样本，未出现不等于零。机构、普通营业部、股通席位按证券/席位/区间/事由去重，不将一日与三日榜重复累计。个股融资按公告/返回说明的最近披露日引用，DOD>50%仅作杠杆异动筛查，核对单位和低基数。

## 3. 日韩早盘与美股期货 / 夜盘

- 通过 lookup 先查日经 225 / TOPIX、KOSPI / KOSDAQ 的真实指数身份与市场代码，再取行情；本手册没有已确认的日韩代码，不能猜 setcode 或把 ETF/期货当现货指数。
- 正常交易日当地 09:00（北京时间 08:00）开盘，T 08:30 可观察早盘。必须有 T 当天且不晚于截止的时点，写北京时间和延迟状态。只有前收涨跌幅时，不描述“开盘后拉升/回落”；需要开盘及最新点位才有此依据。
- 数据通道缺失时，可用 `wenda_news_query` 的截止前早盘快讯补充，读取正文核验；休市、无报价、无法复原历史分别说明。
- 美股股指期货先 lookup 与核验期货工具支持的市场，记录合约、比较基准和报价时间。不能假设内盘期货接口必然支持海外股指。
- 美股夜盘必须标明股票/ETF、实际时段与时点。北京时间 08:30 不是美股常规盘前：常规盘前自美东 04:00 开始，对应北京时间夏令时 16:00、冬令时 17:00。
- 本 Skill 限定通达信；日韩或期货无数据时直接降级，不虚构可用通道，也不自动改用外部搜索。

## 4. 商品与汇率

`tdx_futures_quotes` 的既有内盘线索：setDomain=30，subCode=AU/CU/SC/AG；其他市场代码先 lookup。写清是内盘品种，区分最近夜盘与当前交易，不作为外盘现货的同义替代。报价日、合约、涨跌基准与时间均核验。

DXY、CNH 即期在既有配置中没有已确认的行情通道；可用 `wenda_news_query` 检索对应快讯，标媒体、币对与报价时间。`wenda_macro_query` 中的人民币中间价和银行牌价不是 CNH 即期；当天未公布就不填当天值。

## 5. 新闻、公告与宏观

| 工具 | 参数线索 | 核验要点 |
| --- | --- | --- |
| `wenda_news_query` | keyword、category、date_range、limit | 读取正文，新闻发布时间与事件时间分别检查；窗口 P 收盘至 T 截止 |
| `wenda_notice_query` | code、notice_type、date_range、limit | 实际候选公告，确认证券身份、原文及截止前可用性 |
| `wenda_report_query` | code、keyword、date_range、limit | 研报属于观点，不能当公司公告 |
| `wenda_macro_query` | query 管道格式：主体\|开始日 YYYYMMDD\|结束日 YYYYMMDD\|关键词\|补充 | 按发布时点过滤宏观数据；今日事件只写截止前已知日程/预期 |
| `tdx_ai_listening` | setcode_code、date | 只作线索，回查事件原文发布时间；历史补跑的整日摘要可能含截止后信息 |

人民币中间价已有有效关键词为“人民币汇率中间价”；如返回每 100 美元口径，先核对单位再换算。不能用关键词“美元指数/离岸人民币”命中的有效汇率或离岸商品价格冒充目标报价。

只取影响今日判断的宏观或消息，长假后覆盖整个间隔；原始值即便属于过去统计月份，若在 T 08:30 后公布，也不属于本报告可用事实。

## 6. 按需深度核验与降级

`tdx_security_deep_info` 先 lookup 锁定 entity_type，查询具体候选的公告风险、流动性、资金或基本资料。`tdx_api_data` 仅在已知 schema/entry 时补充板块或数据缺口，不反复猜底层参数。技术指标如需 `tdx_technical_indicator_lookup/query`，先查指标与参数，再限定截至 P。

临时连接失败最多重试一次；结构性缺失与尚未披露按已核验证据分类，不反复请求。westock的margin空表、日韩403和calendar日期序列是另一通道的记录，不能据此判通达信同样不可用。P 的行情和日期不可核验则输出短报；日韩、期货、汇率等缺失则收缩相应结论，不把无数据理解成利空。重要事件附来源链接或公告编号；行情附工具来源与实际时点。

交易时段参考：[Nasdaq](https://www.nasdaq.com/market-activity/stock-market-holiday-schedule)、[JPX](https://www.jpx.co.jp/equities/trading/domestic/01.html)、[KRX](https://regulation.krx.co.kr/contents/RGL/03/03020401/RGL03020401.jsp)。

北向披露依据：[上交所上证发〔2024〕106号](https://www.sse.com.cn/lawandrules/sselawsrules2025/global/hkexsc/c/c_20250613_10781806.shtml)、[深交所深证上〔2024〕601号](https://www.szse.cn/szhk/hkbussiness/news/t20240726_608353.html)。披露期持股只作结构背景，不能反推每日净买入。

交叉核对只用本版本允许的通达信渠道（含可回查原文的wenda新闻）：同日同范围成交额多源差>1%并列，涨跌停若有媒体口径则并列，缺口不静默切WebSearch。未来若拿到期货数据须逐项写延迟状态、时点与基准，不用较新期货覆盖现货收盘。

## 7. 完整分析模块的补充取数

- **上一交易日时间线**：`tdx_kline` 取 P 的 1m/5m 序列（实际周期以 schema 为准），覆盖上证、创业板与 P 的 2–3 只主线股；每标的取一次并核验日期。保留标签、日内形状、轨迹、名场面、节点表，补充 P 收盘至 T 截止的消息节点。
- **分类资金表与持仓分析**：`tdx_screener` 和 `tdx_security_deep_info` 覆盖主力、机构/游资/沪深股通专用席位与个股融资数据，明确各自统计期及口径，不把持股变化写成实时净流入。持仓体检仅使用用户提供或已授权的实际持仓，无资料按模板跳过。
- **板块底层入口（历史调用线索）**：`tdx_api_data` entry="TdxSharePCCW.skef10_bk_cpbd_jczl"、branch="003"、code=实际板块、timeType="1m"；热点题材族 entry="TdxSharePCCW.tdxf10_gg_rdtc"、fixedTag="zttzbkz"、responseTransform preset="hot_topic_board_family"。按实际 schema 核验，不默认其支持 P 历史截面。
- **技术指标**：先 `tdx_technical_indicator_lookup` 获取指标 id/set/parameters，再 `tdx_technical_indicator_query`；代码格式、周期与支持日期以 schema 为准，日线/均线只计算到 P。保留 MACD/KDJ/BOLL 等对具名计划的佐证，不以 T 未完成 K 线计算。
- **晋级与反包**：保留连续连板分布、N 天 M 板、板型、封单、打开次数及梯队断层分析。晋级率要比较完整同口径前后池，所有已实现结果截止 P；今日晋级是待验证条件。

## 8. 从板块比较到执行条件的取数

1. **比较范围**：先查 P 的完整行业范围与涨跌排名（核验分页），再查主要概念/题材；保留各方向的分类、代码和成分范围，行业与概念不混算。逐项补截至 P 的近5个交易日涨跌幅、成交额/同口径变化、成分上涨数与总数、核心/中军/后排；有资金数据再判断净流向。无法获得完整范围时写覆盖限制，不能宣称全市场只有所取的几个方向。
2. **持续性**：近5日收益使用 P 收盘 / P 前第5个交易日收盘 − 1（或明确口径的供应商字段），不是5条日线首尾直接当5日；价格复权一致。单日板块涨幅、资金估算、龙虎榜与融资分别保存来源和统计期；同一供应商派生指标不当作多份独立资金证据。
3. **候选归属**：每个主攻/备选方向分别查成分与候选，确认业务关联及核心/中军/弹性/接力角色；查询实际候选截至截止时刻的公司公告、停复牌/减持/解禁等相关事件，不能只查行业新闻。未查全就注明覆盖，不写“无风险公告”。
4. **价格与成交基准**：候选取 P 收盘、高低点、成交额及所需历史K线；比较板块与个股时统一涨跌基准和时点。计划用“10:00较昨日同时段放量”时，盘前先保存 P 09:30–10:00 累计成交额，确认分钟字段是单根还是累计、是否含竞价；无历史分钟数据就改用可取得指标，不能拿开盘半小时对比昨日全天。
5. **条件交付**：向第7段提供具体基准值、来源/日期/复权方式及可取得的盘中核验字段；今日首15分钟高低点等仅交付计算窗口，08:30不填未来数值。策略阈值另标依据；缺输入的条件降级观察。午报沿相同成分池、资金口径、比较窗口及 M0/B/S 编号核验，不能切换指标来证明原判断正确。

取数通道限定通达信：`tdx_lookup_stock` / `tdx_screener` 核验板块成分与候选，`tdx_quotes` / `tdx_kline` 核验历史基准，`tdx_security_deep_info` 补资金及主体资料，`wenda_notice_query` / `wenda_news_query` 查公告与事件。参数和历史支持以本次 schema 为准。
