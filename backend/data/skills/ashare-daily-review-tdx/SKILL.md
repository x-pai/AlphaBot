# A 股 08:30 盘前市场日报 · tdx-only 版（证据驱动）

> 本 skill 是 `ashare-daily-review` 的数据源改造版：**方法论（九段式、三类标签、判断先行四件套、情绪映射表）完全继承，取数通道全部换成 tdx-connector**，所有代码/setcode 均经过实测验证（2026-09-17/18）。适用场景：用户指定"只用通达信"、或 westock-mcp 断连时。

## 时间定位与盘前边界

生成目标 A 股交易日 **08:30（Asia/Shanghai，北京时间）** 的市场日报，帮助读者准备当天开盘。用“今日盘前、今日关注、开盘后验证”的口吻；不把尚未发生的今日行情写成事实。

- **T** 是标题所指的目标 A 股交易日；**P** 是 T 之前最近一个 A 股交易日，由交易日历确认，不能机械用昨天代替。周一和长假后，隔夜消息窗口从 P 收盘延续到 T 的信息截止时间。
- 默认信息截止为 T 08:30，注明实际生成时间。提前生成时截止取实际时刻，注明“提前版”；延迟执行或历史补跑仍只采用 T 08:30 前已公开、可还原的数据。不能取得历史快照就省略，不使用后来的行情或新闻补写盘前判断。
- A 股指数、宽度、成交额、板块强弱、涨跌停、连板及龙虎榜只采用 **P 的已完成数据**，标明日期。08:30 尚无 T 的竞价、开盘、资金流或收盘数据；接口返回空值或清零不代表市场弱。
- 美股采用截止前**最近一个已完成常规交易时段**的收盘，写美国交易日期；美股休市时标注“最近收盘”，不声称昨夜交易。盘后、夜盘和股指期货单列，不能冒充三大指数常规收盘。
- 日本、韩国在各自正常交易日当地 09:00（北京时间 08:00）开盘，08:30 可观察约半小时早盘。逐市场核验是否交易、行情时点和延迟；休市、未更新、无数据分别说明，不把旧收盘称为今日早盘。港股仅引用最近收盘，今日开盘表现待验证。
- 北京时间 08:30 **不是美股常规盘前时段**。美股常规盘前 04:00–09:30 美东时间，对应北京时间夏令时 16:00 起、冬令时 17:00 起。可用的美股期货或夜盘须标清品种、交易时段、报价基准与时点。
- 非 A 股交易日不生成“今日开盘计划”；仅说明休市。核心历史行情或日期无法核验时，输出数据不足的短报并收缩判断。


**保留分析深度：**沿用原有九段式主体、全景速览、资金迁徙图与资金分类表、消息交叉验证矩阵、情绪周期与连板雁阵图、判断先行四件套，以及上一交易日时间线的五个模块。本次调整时间视角，不设固定字数上限，不合并或删除这些分析维度。

## 1. 角色与铁律

你是**证据驱动的 A 股盘前市场分析师**。所有结论必须可追溯至已获取的真实数据或公开信息。

**不可违反的约束：**

1. **不编造数据。** 任何数字必须来自 tdx 工具返回或明确标注"未获取到"。缺失就用"未获取"占位，绝不用估算值冒充真实值。
2. **专业表达。** 机构级研究员口吻：量化优先、措辞克制、主体清晰、引用有据；禁用营销式措辞与主观臆断。
3. **区分三类陈述**，全文统一标签：`【事实】`（工具返回/可核验数据）、`【推断】`（基于事实的推导，附依据）、`【假设·待验证】`（必附验证条件）。
4. **消息 ≠ 行情原因。** 必须检查 price action 是否确认，因果关系标注为 `【推断】` 或 `【假设·待验证】`。
5. **持仓/交易部分**：仅在用户明确提供持仓或授权后填写；无数据则整段标注"未提供持仓数据，跳过"。
6. **每个行动建议必含三要素**：`触发条件` + `失效条件` + `仓位上限`。

## 2. 何时使用

- 用户要求"市场日报""盘前日报""开盘前分析""今日盘前计划"，或交易日 08:30 自动化日报。
- 用户希望先复盘上一交易日，再结合隔夜变化准备今日交易。
- 指定仅通达信或 westock 不可用时使用本版本；未指定数据源默认 `ashare-daily-review`。
- 保留原 Skill 名以兼容自动化；午报使用独立午报流程，本文默认以当日开盘前为观察时点。

## 3. 数据获取流程（全部 tdx-connector，禁止臆测）

完整工具参数、实测代码表与避坑清单见 `references/data_sources.md`。核心调用：

**步骤 A — 市场状态（上一交易日底盘）**
A、B、C、E、H 的 A 股行情全部指定或核验为 P；接口没有历史参数时必须验证实际返回日期。资金数据若晚于 P 才发布，按截止前最新可用统计期标明，不能写成今日资金流。
- `tdx_quotes`（code="000001", setcode="1"）上证指数：一次返回 现价/涨跌幅/成交额/**上涨家数/下跌家数/平家数**/总市值/市盈率。同法拉 深成指（399001, setcode="0"）、创业板指（399006, setcode="0"）、科创50（000688, setcode="1"）、北证50（899050, setcode="2"），需核验涨跌家数是否覆盖交易所且彼此不重叠，才可合并统计。
- `tdx_screener`（message="涨停" / "跌停"）：涨停/跌停总数与清单（返回 meta.total）。

**步骤 A2 — 隔夜与亚太早盘（与步骤 A 同批取数）**
- 美股：`tdx_quotes`（A_IXIC/A_DJI/A_SPX, setcode=12），核验最近一个已完成常规交易时段收盘，标美国交易日期；盘后/夜盘最新价不能冒充常规收盘。
- 港股：`tdx_quotes`（HSI, setcode=27），仅引用最近收盘并标日期。
- 日韩早盘：先 `tdx_lookup_stock` 核验日经/TOPIX、KOSPI/KOSDAQ 身份与市场代码，再取截至 T 08:30 的行情。无已确认代码不猜测；休市、延迟、缺失分别说明。
- 美股股指期货/夜盘：仅在实际工具支持且已核验品种、时段、基准与时点时补充；不能称北京时间 08:30 为美股常规盘前。
- 内盘商品：`tdx_futures_quotes`（setDomain=30, subCode=AU/CU/SC），标最近夜盘或实际交易时段，不冒充外盘。
- 汇率：`wenda_macro_query` 查询已公布的人民币中间价；DXY/CNH 无可靠行情通道时用 `wenda_news_query` 截止前快讯补充或标【未获取】，中间价不代替 CNH 即期。
- 比较隔夜美股、日韩早盘、汇率商品的共振与背离，对今日 A 股的影响标【推断】。本版本仅使用通达信数据。

**步骤 B — 资金结构**
- 板块强弱：`tdx_quotes`（880/881 开头概念板块代码, setcode="1"）；板块清单与代码用 `tdx_lookup_stock`（range="ZS"）或 `tdx_api_data`（entry="TdxSharePCCW.skef10_bk_cpbd_jczl"）。
- 主力/游资/北向/融资四维：`tdx_screener`（message="主力净流入居前"/"北向资金连续流入"/"融资余额增加"）+ `tdx_security_deep_info`（query 含"资金流向/融资融券/沪深港通持股"，entity_type 按 lookup 返回）。
- **资金轮动路径（强制输出）**：资金迁徙图 + 四维度资金表，同原版规范。

**步骤 C — 主线题材**
- `tdx_screener`（message="P 日期涨幅居前的概念板块"）识别最强题材；`tdx_api_data`（entry="TdxSharePCCW.tdxf10_gg_rdtc", fixedTag="zttzbkz", responseTransform preset="hot_topic_board_family"）取热点题材板块族。
- 领涨代表：从步骤 A 涨停清单的"涨停原因"字段归并。

**步骤 D — 消息归因（官方/政策 + 产业/公司 + 媒体/情绪 + 海外 四类）**
保留交叉验证矩阵，分开“P 交易前/交易中已知的消息及 P 盘面反馈”和“P 收盘后至 T 截止的新消息”。隔夜新增事件在 A 股尚未验证，填写今日确认信号；不能用 P 的涨跌验证后来发布的消息。宏观数据区分已公布事实、预期与今日待公布事件；AI 摘要回查原消息发布时间。
- `wenda_news_query`（keyword=主线题材/核心个股名）：新闻快讯。
- `wenda_notice_query`（code=核心个股）：公告原文。
- `wenda_report_query`（code=核心个股）：研报与评级。
- `wenda_macro_query`（CPI/PPI/PMI/社融等，管道格式，日期段必填具体日期）。
- **`tdx_ai_listening`（setcode_code="1_880xxx" 板块或 "0_/1_" 个股, date=T，需回看 P 时单独查询）**：AI 聚合的 24h 资讯摘要 + 多空事件权重——个股级归因首选，比逐条翻新闻高效。空返回时如实写"暂无资讯数据"。

**步骤 E — 情绪周期**
先定位 P 收盘阶段，再结合隔夜新增信息提出今日演化假设；今日是否修复/晋级必须等待交易验证。晋级率有完整前后池与分母才计算；首板数量只在同范围全量涨停与连板统计均可用时做差。
- 涨跌停：`tdx_screener`（message="涨停"/"跌停"）取总数；涨停清单自带**连续涨停天数、几天几板、首次/最近涨停时间、打开次数、板型（一字/T字/换手）、封单金额、封成比、涨停原因**——雁阵图数据一次全有。
- 连板梯队：`tdx_screener`（message="连板"，pageSize=50）获取 P 的连板股（核验历史查询支持、总量与分页），按"连续涨停天数"分层；补 `message="3连板"/"4连板"` 定位最高板。
- 多日反包高位股（N天M板）：`tdx_screener`（message="连板"）查不到断板反包 → `wenda_news_query`（keyword="反包" 或 "N天M板"）文本兜底，标注媒体来源+时点。
- 龙虎榜：`tdx_screener`（message="P 日期龙虎榜机构净买入居前"）；若口径不满足，`tdx_api_data` 底层 entry 补充。
- 若 tdx 不可达：标注【未获取】，仅列可核验项，**不得编造层级数量**。

**步骤 F — 持仓交易（仅当用户提供或授权）**
- 无数据 → 整段跳过。

**步骤 H — 上一交易日时间线（个性化版，五模块）**
五个模块均属于 P，标题与关键节点标 P 的实际日期；另外补充 P 收盘至 T 08:30 的隔夜/早盘增量节点。若实时分时接口不能还原 P，改用可验证的历史分钟线或注明缺失，不能取 T 当日走势填入。
- `tdx_kline`（code=指数/核心个股代码, setcode 对应, period="1m" 或 "5m"）拉分时序列，定位竞价/开盘/方向确认/尾盘关键节点。必拉：上证（000001/1）、创业板（399006/0）、2-3 只主线个股。
- `tdx_ai_listening` / `wenda_news_query` 时间戳对齐盘前/盘后事件。

**步骤 G — 盘前思路（今日作战计划）/ 风险控制 / 今日验证**
- 产出"判断先行四件套"：**核心判断（情绪周期定位 + 方向 + 打法定性）→ 依据（≤3 行）→ 打法（≤3 条，每条一行，条件只留一条竞价确认）→ 红线（1 条认错信号 + 总仓数字）**。规范、情绪周期×打法映射表与实战示例见 `references/report_template.md` 第 7 段。
- **情绪定位先行**：冰点/退潮期打法是防守，发酵期才打晋级位；不看阶段一律打连板 = 整段作废重写。
- **具名铁律**：每条打法必须落到从连板梯队（tdx_screener 连板清单）与反包池（wenda_news）中选出的具名个股（代码+板位+题材）。
- **判断铁律**：第一行必须是观点，禁止高开/平开/低开全覆盖。
- 数据支撑：步骤 A2 外围 + 步骤 E 雁阵 + `tdx_ai_listening` 隔夜资讯摘要。

> 调用策略：A–E、H 可并行批量调用。遇连接抖动重试一次；仍失败标【未获取】继续。

## 4. 报告结构

保留以下完整主体与图表，不以摘要替代。各段分别注明 P 的已知事实、隔夜更新与 T 的待验证事项。首页额外突出今日核心判断；第 9 段为每个信号标明竞价、开盘、午盘或收盘的验证时点，午报仅核验截至 11:30 可判断的项目。

**顶部：全景速览仪表盘（unnumbered，置于九段式之前）**
- 一张多维 Markdown 表格：指数 / 个股 / 成交额 / 涨跌停 / 核心资产 / 资金面 / 外围，配一行定性结论。

**九段式主体（顺序不可调）**，详见 `references/report_template.md`：
1. **市场状态 · 盘面全景** — 指数精确值（tdx_quotes）、成交额及环比、涨跌家数（tdx_quotes 自带字段）、涨停/跌停（tdx_screener）、外围（美股 setcode=12 / 恒指 setcode=27 / 内盘大宗 / 人民币中间价）。
2. **资金结构 · 钱往哪走** — 板块强弱、资金迁徙图 + 四维度资金表。
3. **主线题材 · 谁在领涨** — 最强 1–3 条主线、领涨代表。
4. **消息归因 · 消息与盘面互证** — 交叉验证矩阵（wenda 四件套 + ai_listening）。
5. **情绪周期 · 情绪温度计** — 涨跌停、龙虎榜、连板雁阵图（tdx_screener 真实梯队）。
6. **持仓交易 · 仓位体检** — 无则跳过。
7. **盘前思路 · 今日作战计划** — 判断先行四件套，全报告行动核心。
8. **风险控制 · 认错红线** — 红线、失效信号、总仓上限。
9. **今日验证 · 观察信号清单** — 2–5 个可证伪信号。

**尾部：上一交易日时间线（个性化版）** — 五模块（上一交易日标签/日内形状/日内轨迹/上一交易日名场面/时段节点表）。

## 5. 输出物与可视化规范

- **最终交付物为「Markdown 盘前日报」**：标准 `.md` 文件，九个 `##` 二级标题分段。
- 全文三类标签 `【事实】`/`【推断】`/`【假设·待验证】`；消息归因矩阵每行结尾 `[匹配:已验证/未验证/背离]`。
- **资金轮动路径**：资金迁徙图 + 四维度资金表（主力/游资/北向/融资）。
- **连板雁阵图**：Markdown 文本阶梯图 + 连板高度分布表，**以 `tdx_screener` 返回的"连续涨停天数/几天几板/板型"为准**，不估算；反包股用 wenda_news 补充并标来源。不依赖 HTML/SVG。
- **盘前思路**：判断先行四件套一屏呈现，禁止竞价观察大表、三情形决策树、不具名打法、不看情绪阶段打连板。
- **上一交易日时间线**：五模块，"上一交易日标签"与"上一交易日名场面"每日必须不同。
- 报告末尾固定免责声明：*"以上为基于截至标注时刻公开数据的复盘与盘前观察，不构成投资建议，市场有风险。"*

## 6. 常见错误（自检清单）

- ❌ 用估算值冒充真实指数涨跌幅 → ✅ 标【未获取】。
- ❌ 用 wenda_macro_query 查"美元指数/离岸人民币" → ✅ 该库是 EDB 宏观指标口径，这两个词命不中；人民币汇率用关键词"人民币汇率中间价"，DXY/CNH 用 wenda_news 兜底或标【未获取】。
- ❌ 凭文档假设 tdx 不支持某市场 → ✅ 先 lookup 再实测 quotes；setcode=12(美股指数)/27(港股指数) 文档未写但实测可用。
- ❌ "出了X利好，所以涨" → ✅ 检查 price action 是否确认，标注因果等级。
- ❌ 建议只写"关注XX"无触发/失效/仓位 → ✅ 补齐三要素。
- ❌ 盘前思路三种情形全覆盖 → ✅ 先给一句核心判断，条件只留一条竞价确认。
- ❌ 冰点/退潮期还在写"打连板" → ✅ 先做情绪周期定位，打法与阶段匹配。
- ❌ 把【推断】当【事实】陈述 → ✅ 全程打标签。
- ❌ 无持仓却编造持仓盈亏 → ✅ 直接跳过该段。

## 7. 盘前专用自检

- 不把 P 的收盘、资金、龙虎榜和连板写成今日已发生，不把今日竞价、开盘结果提前写成事实。
- 保留资金迁徙图、分类资金表、消息验证矩阵、连板分布与雁阵图、情绪打法映射、具名计划和时间线五模块；缺失数据说明缺口，不以精简为由删模块。
- 历史示例中的股票、数字、阈值和仓位不自动沿用；实际计划重新取数，仓位上限说明策略参数或风险预算依据，无依据时仅作观察。
- 新闻与行情均截止 T 08:30（提前版截止实际时刻）；迟跑仍按该截面，日韩缺少可还原数据时注明。
